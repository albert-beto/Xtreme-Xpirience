# Xtreme-Xpirience
Xtreme Xpirirence, constă în realizarea unei mașinuțe inteligente și interactive, concepută pentru a combina tehnologia cu partea practică și distractivă. Aceasta demonstrează modul în care cunoștințele din programare, electronică și automatizare pot fi aplicate într-un proiect funcțional și atractiv.
